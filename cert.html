Pasang sertifikat kiosk

Cukup sekali per tablet. Setelah ini Chrome tidak memberi peringatan lagi, dan app bisa di-install ke homescreen dengan mode offline.

Download sertifikat

Android (tablet Advan)

  1. Tap tombol Download sertifikat di atas.
  2. Buka Settings → Security / Keamanan → Encryption & credentials → Install a certificate → CA certificate. (Kalau tidak ketemu, cari "certificate" di kolom pencarian Settings.)
  3. Tap Install anyway, buka PIN/pola layar kalau diminta, lalu pilih file curious-art-kiosk-ca.crt dari Downloads.
  4. Tutup Chrome sepenuhnya (swipe dari recent apps), lalu buka lagi.
  5. Buka https://<IP komputer>:5192. Harusnya tanpa peringatan.
  6. Menu ⋮ → Add to Home screen / Install app.

iPad / iPhone

  1. Download sertifikat di Safari, lalu tap Allow.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → nyalakan Curious Art Photo Kiosk CA.

Sertifikat ini hanya berlaku untuk komputer kiosk ini. Kalau IP komputer berubah, tidak perlu pasang ulang.
